# ความจำโปรเจกต์: สมัครสมาชิกและโหลดข้อมูลตอนล็อกอิน

## ขอบเขต

- เก็บข้อกำหนดเกี่ยวกับการสมัครสมาชิกและการดึงข้อมูลบัญชีตอนล็อกอิน
- เก็บไว้ในโฟลเดอร์ `project-memory/` แยกจาก `src/` และไฟล์เดิม
- เก็บไฟล์ CSV ในโฟลเดอร์ `data/` แยกจากโค้ดใน `src/` และบันทึกความจำใน `project-memory/`
- แยก CSV ตามชนิดข้อมูล: `users.csv`, `reviews.csv`, `favorites.csv` และ `read_chapters.csv`
- `data/favorites.csv` เก็บ `email`, `bookId`, `bookTitle`
- `data/read_chapters.csv` เก็บ `email`, `bookId`, `bookTitle`, `chapterIndex`, `chapterTitle`
- เป้าหมายคือให้แต่ละบัญชีเห็นข้อมูลของตัวเองหลังเข้าสู่ระบบ

## ข้อมูลสำหรับล็อกอิน

- ใช้อีเมลและรหัสผ่านที่ผู้ใช้กรอก เพื่อตรวจสอบบัญชีและอนุญาตให้ล็อกอิน

## ข้อมูลตอนสมัครสมาชิก

- ต้องกรอกชื่อผู้ใช้ อีเมล และรหัสผ่าน
- ต้องกรอกรหัสผ่านยืนยันอีกครั้ง และค่าทั้งสองช่องต้องตรงกัน
- ต้องติ๊กยอมรับเงื่อนไขการใช้งานก่อนสมัคร
- โปรเจกต์นี้เก็บรหัสผ่านเป็นข้อความตรง ๆ ใน `users.csv` เพื่อให้โค้ดตัวอย่างเข้าใจง่าย
- เก็บบัญชีใน `data/users.csv` โดยมีคอลัมน์ `username`, `email`, `password`

## หลังล็อกอินและการเขียนรีวิว

- แสดงชื่อผู้ใช้ที่มุมซ้ายล่างของแถบเมนู
- โหลดข้อมูลรายการโปรดและประวัติอ่านของบัญชีปัจจุบันกลับมา
- เมื่อเพิ่ม/ลบรายการโปรดหรือทำเครื่องหมายตอนว่าอ่านแล้ว ให้บันทึกการเปลี่ยนแปลงผูกกับบัญชี
- ประวัติอ่านต้องระบุหนังสือและตอนที่อ่านแล้ว ไม่ใช่แค่สถานะของทั้งเล่ม
- เมื่อเปิดสารบัญ ให้แสดงสถานะ "อ่านแล้ว" เฉพาะตอนที่ผู้ใช้เคยทำเครื่องหมายไว้
- ผูกชื่อผู้ใช้และอีเมลของบัญชีกับคอมเมนต์หรือคะแนนที่ส่ง
- แสดงชื่อผู้ใช้ต่อคนอื่นในคอมเมนต์และคะแนน
- เก็บอีเมลไว้ใน CSV สำหรับดูภายในเท่านั้น ไม่แสดงต่อผู้ใช้อื่น
- ไม่จำเป็นต้องบันทึกวันที่ส่งรีวิวหรือคะแนน
- เก็บรีวิวใน `data/reviews.csv` โดยมีคอลัมน์ `bookId`, `bookTitle`, `username`, `email`, `rating`, `comment`
- ผู้ใช้ส่งรีวิว/คะแนนซ้ำให้หนังสือเล่มเดิมได้ แต่ละครั้งเป็นรายการใหม่
- ให้คะแนนพร้อมคอมเมนต์ ไม่จำเป็นต้องรองรับการส่งคะแนนอย่างเดียว

## สถานะ

- โค้ด CSV แยกจาก UI อยู่ใน `src/storage/CsvStorage.java`
- `Main` สร้างไฟล์ CSV ที่ขาดใน `data/` และโหลดรีวิวเมื่อเริ่มโปรแกรม
- CSV เชื่อมกับ UI แล้ว; ให้เปิดโปรแกรมจากโฟลเดอร์หลักของโปรเจกต์
