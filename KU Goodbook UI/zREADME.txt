สินคนเลว (SinConLeew Reader)
=============================

โปรแกรมอ่านหนังสือและนิยายบนเดสก์ท็อป พัฒนาด้วย Java Swing ตัวอย่างนี้รวมหน้ารายการหนังสือ หน้ารายละเอียด หน้าอ่าน และหน้าสำหรับเข้าสู่ระบบ/สมัครสมาชิก

คุณสมบัติ
---------
- หน้าแรกแสดงหนังสือ 8 เรื่อง พร้อมตัวเลือกค้นหา เรียงลำดับ และหมวดหมู่
- หน้ารายละเอียดแสดงปก ข้อมูลหนังสือ สารบัญ และส่วนรีวิวตัวอย่าง
- หน้าอ่านแสดงเนื้อหาแบบแบ่งย่อหน้า ปรับขนาดตัวอักษรด้วยปุ่ม A- และ A+
- หน้าเข้าสู่ระบบและสมัครสมาชิกเป็นส่วนติดต่อผู้ใช้ตัวอย่าง
- ใช้ธีมสีกระดาษและฟอนต์ที่กำหนดจาก Theme.java

ความต้องการ
-----------
- JDK 8 หรือใหม่กว่า
- ฟอนต์ที่รองรับภาษาไทย เช่น Leelawadee UI, Sarabun หรือ Tahoma

วิธีคอมไพล์และเปิดโปรแกรม
------------------------
เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:

    javac -encoding UTF-8 *.java
    java HomeScreen

หากต้องการเปิดหน้าจออื่น ให้ใช้ชื่อคลาสแทน HomeScreen เช่น:

    java DetailScreen
    java ReaderScreen
    java LoginScreen
    java RegisterScreen

ไฟล์ในโปรเจกต์
--------------
- AppHeader.java: แถบส่วนหัวที่ใช้ร่วมกันในแต่ละหน้า
- BookCard.java: การ์ดข้อมูลหนังสือสำหรับหน้าแรก
- CoverPanel.java: แผงแสดงหน้าปกหนังสือ
- Theme.java: สีและฟอนต์ส่วนกลางของโปรแกรม
- HomeScreen.java: หน้ารายการหนังสือ
- DetailScreen.java: หน้ารายละเอียดหนังสือ สารบัญ และรีวิว
- ReaderScreen.java: หน้าอ่านเนื้อหาและปรับขนาดตัวอักษร
- LoginScreen.java: หน้าเข้าสู่ระบบ
- RegisterScreen.java: หน้าสมัครสมาชิก

หมายเหตุ
--------
โปรเจกต์นี้เป็นส่วนติดต่อผู้ใช้ตัวอย่าง ยังไม่มีฐานข้อมูลหรือระบบยืนยันตัวตนจริง และปุ่มนำทาง/ส่งรีวิวบางส่วนยังไม่ได้เชื่อมต่อการทำงาน
