# KU Goodbook — แอปอ่านหนังสือด้วย Java Swing

README ฉบับนี้อธิบายวิธีคอมไพล์และเปิดแอป โครงสร้างโปรเจกต์ ความรับผิดชอบ
ของแต่ละหน้า และหน้าที่ของเมธอดในซอร์สโค้ดแต่ละคลาส รวมถึงระบุพฤติกรรมที่เป็น
เพียง UI ตัวอย่างและยังไม่ได้เชื่อมการทำงานจริง

> โปรเจกต์นี้เป็น desktop UI prototype ข้อมูลหนังสือฝังอยู่ใน Java ไม่มี backend
> ไม่มีระบบบัญชี และไม่มีการบันทึกข้อมูลลงดิสก์

## ข้อกำหนดและเริ่มต้นใช้งาน

- JDK 17 ขึ้นไป โดยต้องเรียก `javac` และ `java` ได้จาก PowerShell
- เปิดคำสั่งจากโฟลเดอร์รากโปรเจกต์
- ฟอนต์อยู่ใน `fonts/` ที่โฟลเดอร์ราก
- ไม่มีไลบรารีภายนอกที่ต้องติดตั้งเพิ่ม

โครงสร้างหลัก:

```text
.
├── fonts/
│   ├── Chonburi-Regular.ttf
│   ├── Pridi-Regular.ttf
│   ├── Sarabun-Bold.ttf
│   └── Sarabun-Regular.ttf
├── src/
│   ├── app/          จุดเริ่มโปรแกรมและการนำทาง
│   ├── components/   ส่วนประกอบ UI ที่นำกลับมาใช้ซ้ำ
│   ├── data/         โครงสร้างและชุดข้อมูลตัวอย่าง
│   ├── screens/      หน้าจอแต่ละหน้า
│   └── theme/        สีและฟอนต์
└── README.md         คู่มือใช้งานและเอกสารส่งต่องาน
```

## โครงสร้างและภาพรวมการทำงาน

`app.Main` เรียก `LoginScreen` บน Swing Event Dispatch Thread (EDT) จากนั้น
ปุ่มและเมนูเรียกเมธอดใน `app.Nav` เพื่อเปิดหน้าต่างใหม่และปิดหน้าต่างเดิม
หน้าต่างแต่ละหน้าสร้าง UI จากคลาสใน `components/` ดึงข้อมูลจาก `data/`
และเรียกใช้สี/ฟอนต์จาก `theme/`

```text
Main
 └─ LoginScreen
     ├─ Nav → Home / Register / Login / Favorites / Categories / Detail / Reader
     ├─ components → controls, cards, sidebar, covers
     ├─ BookData.ALL → รายการหนังสือตัวอย่าง
     └─ Theme + Fonts → รูปลักษณ์
```

Swing UI ควรถูกสร้างหรืออัปเดตบน EDT เช่น `SwingUtilities.invokeLater(...)`
ที่ใช้ใน `main()` ของหน้าจอต่าง ๆ

## แนวทางพัฒนาต่อและส่งมอบงาน

### โครงสร้างและขอบเขตความรับผิดชอบ

- `app/` — จุดเริ่มต้นและการเปลี่ยนหน้าต่าง หลีกเลี่ยงการสร้าง navigation
  logic ซ้ำในแต่ละหน้าจอ
- `screens/` — ประกอบหน้าจอและเชื่อม event ของ UI เข้ากับ `Nav`/ข้อมูล
- `components/` — องค์ประกอบที่ใช้ซ้ำได้ เช่น ปุ่ม ช่องกรอก การ์ด และปก
- `data/` — โครงสร้างหนังสือและข้อมูลตัวอย่าง ยังไม่มี persistence layer
- `theme/` — จุดรวมสี ฟอนต์ และ fallback เมื่อโหลดฟอนต์ไม่ได้

### ขั้นตอนเพิ่มหรือแก้ข้อมูลหนังสือ

1. แก้ข้อมูลตัวอย่างใน static initializer ของ `src/data/BookData.java`
2. เรียก `addChapter(title, text)` ตามลำดับการอ่าน ห้ามเพิ่มชื่อและเนื้อหา
   แยกกันโดยตรง เพราะหน้าจอจับคู่รายการทั้งสองด้วย index
3. เพิ่มรีวิวด้วย `addReview(name, stars, text)` ก่อนเพิ่มหนังสือเข้า `ALL`
4. คอมไพล์ แล้วเปิดหน้ารายละเอียดและหน้าผู้อ่านเพื่อตรวจชื่อ/เนื้อหาตอน

### แนวทางแก้ไขโค้ด

- ใช้ UTF-8 และย่อหน้าด้วยช่องว่าง 4 ตัวในไฟล์ Java
- คงการสร้าง Swing component และอัปเดต UI ไว้บน Event Dispatch Thread
- เขียน JavaDoc ให้ public class หรือ API ที่ต้องเข้าใจจากภายนอก และเขียน
  คอมเมนต์เฉพาะจุดที่อธิบายเหตุผล ข้อจำกัด หรือ invariant ที่โค้ดบอกเองไม่ได้
- ถ้าปุ่มหรือลิงก์เปลี่ยนพฤติกรรม ให้ตรวจว่าปุ่มอื่นในหน้าจอเดียวกันยังทำงาน
  ตามขอบเขตที่ README ระบุ และอัปเดตส่วน “ขอบเขตและสิ่งที่ยังไม่ทำงาน”
- ก่อนส่งงาน ให้คอมไพล์ตามคำสั่งด้านบน และตรวจ flow หลัก:
  เข้าสู่ระบบตัวอย่าง → หน้าแรก → รายละเอียด → เลือกตอน → ตอนก่อนหน้า/ถัดไป

### ขอบเขตการทดสอบในปัจจุบัน

โปรเจกต์ยังไม่มี build system หรือชุด unit/UI tests คำสั่ง `javac` ด้านบน
จึงเป็นการตรวจ compile เท่านั้น ส่วนการเปลี่ยนแปลง UI ต้องเปิดแอปและตรวจ
ด้วยตนเองตาม flow ที่เกี่ยวข้อง

## หน้าจอ

### `app.Main` — จุดเริ่มต้น

เปิด `screens.LoginScreen` เป็นหน้าแรก โดยใช้ `SwingUtilities.invokeLater`
เพื่อสร้างหน้าต่างบน EDT

**เมธอด**

- `main(String[] args)` — จุดเริ่มโปรแกรม ไม่ใช้อาร์กิวเมนต์ และเปิดหน้า Login

### `screens.LoginScreen` — เข้าสู่ระบบ

หน้ากลางจอแบ่งเป็นแผงแบรนด์ทางซ้ายและฟอร์มทางขวา มีช่องชื่อผู้ใช้/อีเมล
ช่องรหัสผ่าน ปุ่มเข้าสู่ระบบ และลิงก์สมัครสมาชิก

**เมธอด**

- `LoginScreen()` — ตั้งค่าหน้าต่าง โหลดฟอนต์ จัดวางแผงแบรนด์กับฟอร์ม
  และแสดงหน้าต่าง ปุ่มเข้าสู่ระบบไปหน้าแรกโดยไม่ตรวจข้อมูลบัญชี
- `makeLabel(String text)` — สร้าง `JLabel` สำหรับชื่อกำกับช่องกรอก
- `makeField(String hint, boolean password)` — สร้างช่องกรอกพร้อม hint;
  เมื่อ `password` เป็นจริง ช่องจะแสดงอักขระรหัสผ่านแบบซ่อน
- `addRow(JPanel form, JComponent c, int gap)` — เพิ่ม component ลงฟอร์ม
  จัดชิดซ้าย และเว้นช่องไฟด้านล่างตาม `gap`
- `main(String[] args)` — เปิด LoginScreen บน EDT เพื่อให้รันทดสอบหน้านี้แยกได้

### `screens.RegisterScreen` — สมัครสมาชิก

แสดงแผงแบรนด์และช่องชื่อผู้ใช้ อีเมล รหัสผ่าน ยืนยันรหัสผ่าน ช่องยอมรับ
เงื่อนไข ปุ่มสมัคร และลิงก์กลับไปหน้าเข้าสู่ระบบ ปุ่มเป็นตัวอย่างและ
ไม่ได้ตรวจหรือบันทึกข้อมูลบัญชี

**เมธอด**

- `RegisterScreen()` — สร้างหน้าต่างและจัดวางฟอร์มสมัครสมาชิก ปุ่มสมัครกับ
  ลิงก์เข้าสู่ระบบเปิดหน้า Login
- `makeLabel(String text)` — สร้าง label กำกับช่องกรอก
- `makeField(String hint, boolean password)` — สร้างช่องกรอกข้อความหรือรหัสผ่าน
- `addRow(JPanel form, JComponent c, int gap)` — เพิ่มแถวลงฟอร์มและกำหนดช่องไฟ
- `main(String[] args)` — เปิด RegisterScreen บน EDT

### `screens.HomeScreen` — หน้าแรก

แสดง Sidebar, ข้อความทักทาย, ช่องค้นหาหน้าตา UI และการ์ดหนังสือทั้งหมด
จาก `BookData.ALL` ในตาราง 3 คอลัมน์ที่เลื่อนได้

**เมธอด**

- `HomeScreen()` — ตั้งค่าหน้าต่าง ประกอบ Sidebar, แถบบน และรายการหนังสือ
- `buildTopBar()` — สร้างข้อความทักทายและช่องค้นหาตกแต่งด้วย `InputField`
- `buildBookList()` — สร้างหัวข้อ ปุ่มเรียง และการ์ดหนังสือทั้งหมดพร้อม
  `JScrollPane` และแถบเลื่อนแบบบาง
- `main(String[] args)` — เปิด HomeScreen บน EDT

**ข้อควรรู้:** ช่องค้นหาและปุ่มเรียงยังไม่มี listener จึงไม่ค้นหรือเรียงข้อมูลจริง

### `screens.FavoritesScreen` — รายการโปรดตัวอย่าง

แสดงหนังสือที่เลือกไว้ล่วงหน้าในอาร์เรย์ `FAVORITES` ซึ่งเป็นดัชนีแบบเริ่มจาก
ศูนย์ของ `BookData.ALL` ปัจจุบันมี 6 รายการ แสดงจำนวน ปุ่มค้นหา ปุ่มเรียง
และการ์ดที่มีปุ่มลบเป็นองค์ประกอบประกอบหน้าจอ

**เมธอด**

- `FavoritesScreen()` — สร้าง Sidebar, หัวข้อ/จำนวนรายการ, ส่วนค้นหา/เรียง
  และตารางการ์ดรายการโปรดที่เลื่อนได้
- `main(String[] args)` — เปิด FavoritesScreen บน EDT

**ข้อควรรู้:** รายการโปรดเป็นค่าคงที่ตัวอย่าง ปุ่มค้นหา เรียง และลบยังไม่
เปลี่ยนข้อมูลจริง

### `screens.CategoriesScreen` — หมวดหมู่

แสดงหมวดหมู่ที่กำหนดไว้ใน `NAMES` เป็นการ์ดสามคอลัมน์ แต่ละการ์ดแสดงชื่อ
และจำนวนหนังสือที่ได้จาก `BookData.byCategory(...)`

**เมธอด**

- `CategoriesScreen()` — ประกอบ Sidebar, หัวหน้า, ช่องค้นหา และตารางหมวดหมู่
- `colorOf(String category)` — เลือกสีจากปกหนังสือรายการแรกในหมวดนั้น
  หากหมวดทั้งหมดหรือไม่มีหนังสือ ให้ใช้สีแดงเบอร์กันดี
- `main(String[] args)` — เปิด CategoriesScreen บน EDT
- `CategoryTile(String name, String count, Color color)` — เก็บข้อมูลชื่อ
  จำนวน และสี พร้อมกำหนดขนาดการ์ด
- `CategoryTile.paintComponent(Graphics g)` — วาดเงา พื้นไล่สี กรอบทอง
  ลายสันหนังสือ และข้อความชื่อ/จำนวนหมวด

**ข้อควรรู้:** ช่องค้นหาและการ์ดหมวดหมู่แสดงหน้าตาเท่านั้น ยังไม่กรองหรือ
นำทางไปหน้ารายการหนังสือของหมวด

### `screens.DetailScreen` — รายละเอียดหนังสือ

รับ `Book` หนึ่งรายการและแสดงปุ่มกลับ ปก/ข้อมูลหนังสือ เรื่องย่อ สารบัญ
คะแนนและรีวิว รวมถึงฟอร์มเขียนรีวิวในคอลัมน์ที่เลื่อนดูได้ สารบัญแต่ละตอน
คลิกเพื่อเปิดหน้าอ่านตอนนั้น สถานะอ่านแล้ว/ตอนถัดไปเป็นตัวอย่างที่ตั้งไว้
โดย `DEMO_READ_COUNT` (สามตอนแรกอ่านแล้ว ตอนที่ 4 เป็นตอนถัดไป)

**เมธอด**

- `DetailScreen(Book book)` — รับหนังสือ จัดวาง Sidebar และส่วนเนื้อหาทั้งหน้า
- `buildBackRow()` — สร้างปุ่มกลับไปหน้าแรก
- `buildHeroCard()` — สร้างปก ชื่อ ผู้แต่ง หมวด ปี สถานะ คะแนน จำนวนรีวิว
  ปุ่มรายการโปรด และเรื่องย่อ
- `buildChapterCard()` — สร้างหัวข้อสารบัญและตารางตอนทั้งหมดของหนังสือ
- `makeChapterTile(int index)` — สร้างแถวตอน แสดงชื่อและป้ายสถานะตัวอย่าง
  ผูกการคลิกเพื่อเปิด `ReaderScreen` ที่ตอนตามดัชนี
- `buildReviewCard()` — สร้างคะแนนเฉลี่ย จำนวนรีวิว และรายการรีวิวทั้งหมด
- `makeReviewRow(String name, int starCount, String text)` — จัดแถวรีวิว
  พร้อมอักษรย่อผู้รีวิว ดาว และข้อความ
- `buildWriteReviewCard()` — สร้างปุ่มดาว ช่องข้อความ และปุ่มส่งรีวิว
- `stars(int count)` — สร้างสตริงดาวเต็ม/ดาวว่างจำนวน 5 ดวงตามคะแนน
- `addToColumn(JPanel column, JComponent c, int gap)` — เพิ่ม component
  ลงคอลัมน์แนวตั้งและเว้นระยะด้านล่าง
- `main(String[] args)` — ถ้ามีเลขให้เปิดหนังสือตามลำดับที่เริ่มจาก 1 และ
  จำกัดค่าให้อยู่ในช่วงรายการ; ถ้าไม่มีก็แสดงกล่องเลือกหนังสือ หากอาร์กิวเมนต์
  ไม่ใช่ตัวเลขจะแจ้งเตือน
- `DefaultListCellRenderer.getListCellRendererComponent(...)` — ปรับรายการ
  ในกล่องเลือกให้แสดงชื่อภาษาไทยของหนังสือแทนข้อความเริ่มต้นของ object

**ข้อควรรู้:** ปุ่มรายการโปรด ปุ่มเลือกดาว และปุ่มส่งรีวิวเป็น UI ตัวอย่าง
ยังไม่เปลี่ยนรายการโปรดหรือบันทึกรีวิว

### `screens.ReaderScreen` — อ่านตอน

รับ `Book` และดัชนีตอนแบบเริ่มจากศูนย์ แสดงแถบบน หน้ากระดาษที่มีชื่อตอนและ
ข้อความ และแถบนำทางตอนก่อนหน้า/ถัดไป ข้อความอยู่ใน `JTextPane` ที่อ่านอย่างเดียว

**เมธอด**

- `ReaderScreen(Book book, int chapterIndex)` — เก็บหนังสือกับดัชนีตอน
  และจัดวางแถบบน หน้ากระดาษ และแถบล่าง
- `buildTopBar()` — แสดงปุ่มกลับไปหน้ารายละเอียด ชื่อเรื่อง/ตอน และปุ่ม
  `A-`, `A+`, โหมดกลางคืน
- `buildPaper()` — สร้างแผงหน้ากระดาษ ชื่อ/เนื้อหาตอน ลายประดับ ริบบิ้น
  และปุ่มทำเครื่องหมายอ่านจบที่วางอยู่นอกกรอบด้านล่าง
- `paintChildren(Graphics g)` ของแผงหน้ากระดาษ — วาด children ตามปกติ
  ก่อนวาดริบบิ้นทับที่มุมกระดาษ
- `paintRibbon(Graphics2D g, int x)` — วาดริบบิ้นสีแดงและเงาบริเวณขอบกระดาษ
- `makeOrnament()` — สร้าง component วาดเส้นประดับไล่สีและข้าวหลามตัดสีทอง
- `paintComponent(Graphics g)` ของ component ประดับ — วาดเส้นสองข้างและ
  ข้าวหลามตัดสีทองตรงกลาง component
- `buildBottomBar()` — สร้างปุ่มตอนก่อนหน้า/ถัดไป ตัวบอกตำแหน่งตอน และจุดสถานะ
- `makeDots()` — วาดจุดแสดงตอนก่อนหน้า ตอนปัจจุบัน และตอนถัดไป โดยอิง
  ดัชนีของตอนที่เปิดอยู่ ไม่ได้บันทึกประวัติการอ่านจริง
- `paintComponent(Graphics g)` ของ component จุดสถานะ — วาดจุดทึบสำหรับ
  ตอนก่อนหน้า วงแหวนสำหรับตอนปัจจุบัน และวงกลมเส้นบางสำหรับตอนถัดไป
- `main(String[] args)` — อ่านเลขหนังสือและเลขตอนแบบเริ่มจาก 1 (ค่าเริ่มต้น
  คือเรื่องแรกตอนแรก) แปลงเป็นดัชนีเริ่มจากศูนย์และจำกัดให้อยู่ในช่วงข้อมูล

**ข้อควรรู้:** ปุ่ม `A-`, `A+`, โหมดกลางคืน และทำเครื่องหมายอ่านจบยังไม่มี
listener; มีเพียงปุ่มกลับและปุ่มเปลี่ยนตอนที่ทำงาน

## ชั้นข้อมูล

### `data.Book` — ข้อมูลหนังสือหนึ่งเรื่อง

เก็บ metadata เป็น fields ได้แก่ `id`, `titleTh`, `titleEn`, `author`,
`category`, `status`, `year`, `rating`, `color` และ `blurb` ตัวแปร
`chapterTitles` กับ `chapterTexts` เป็นรายการคู่กันตาม index ส่วน `reviews`
เก็บแต่ละรีวิวเป็นอาร์เรย์ `{ชื่อ, คะแนนในรูปข้อความ, เนื้อหา}`

**เมธอด**

- `Book(...)` — กำหนด metadata ของหนังสือ และแปลงค่าสี RGB เป็น `Color`
- `addChapter(String title, String text)` — เพิ่มชื่อตอนและเนื้อหาตอนที่
  ตำแหน่งเดียวกันในรายการทั้งสอง
- `addReview(String name, int stars, String text)` — เพิ่มรีวิวในรูป
  `{name, String.valueOf(stars), text}`

### `data.BookData` — ชุดข้อมูลตัวอย่าง

- `ALL` — `ArrayList<Book>` ที่เก็บหนังสือเรียงตามลำดับ ใช้ร่วมกันโดยหน้าจอ
- static initializer — สร้างหนังสือ 8 เรื่อง เติมตอนและรีวิว แล้วเพิ่มเข้า
  `ALL`; ขณะนี้มี 80 ตอนและ 16 รีวิว
- `byCategory(String category)` — สร้างรายการใหม่ ไม่แก้ `ALL`; คืนหนังสือ
  ทั้งหมดเมื่อ category เป็น `"ทั้งหมด"` หรือคืนเฉพาะรายการที่ category
  ตรงกันทุกตัวอักษร

แก้ metadata, เนื้อหาตอน หรือรีวิวตัวอย่างได้ใน static initializer นี้
ข้อมูลเป็น in-memory เท่านั้น การเปลี่ยนข้อมูลระหว่างใช้งานจะไม่ถูกบันทึก
กลับลงไฟล์

## การนำทาง (`app.Nav`)

เมธอดสาธารณะทุกตัวรับ `Component from` เพื่อระบุ component ต้นทาง จากนั้น
เปิดหน้าต่างใหม่ก่อน แล้วจึงปิดหน้าต่างต้นทาง

- `openHome(Component from)` — เปิดหน้าแรก
- `openFavorites(Component from)` — เปิดรายการโปรด
- `openCategories(Component from)` — เปิดหมวดหมู่
- `openLogin(Component from)` — เปิดหน้าเข้าสู่ระบบ
- `openRegister(Component from)` — เปิดหน้าสมัครสมาชิก

  หนังสือที่ระบุตามดัชนีเริ่มจากศูนย์

- `close(Component from)` — เมธอดภายใน ค้นหา `Window` ที่ครอบ component

## แก้ไขข้อมูลและ UI

- ข้อมูลชื่อเรื่อง ผู้แต่ง หมวด ปี คะแนน และเรื่องย่อ: `src/data/BookData.java`
- ชื่อตอน เนื้อหา และรีวิวตัวอย่าง: static initializer ใน `BookData.java`
- รูปแบบ fields และเมธอดเพิ่มตอน/รีวิว: `src/data/Book.java`
- ลำดับและองค์ประกอบของหน้าจอ: ไฟล์ที่เกี่ยวข้องใน `src/screens/`
- การเปลี่ยนหน้าจอหรือพฤติกรรมลิงก์: `src/app/Nav.java`
- รูปแบบปุ่ม การ์ด ปก ช่องกรอก และแถบเลื่อน: `src/components/`
- สีสว่าง/กลางคืน: `src/theme/Theme.java`
- ฟอนต์: `src/theme/Fonts.java` และไฟล์ใน `fonts/`

## ขอบเขตและสิ่งที่ยังไม่ทำงาน

- ไม่มีการสมัคร/เข้าสู่ระบบจริง ไม่มีการยืนยันตัวตนหรือ backend
- ข้อมูลหนังสือ ตอน และรีวิวเป็นข้อมูลฝังในซอร์สโค้ด
- Search และปุ่มเรียงในหน้าแรก/รายการโปรด/หมวดหมู่เป็นองค์ประกอบตกแต่ง
- ปุ่มลบรายการโปรดไม่ได้ลบข้อมูล และรายการโปรดเป็นอาร์เรย์ตัวอย่างคงที่
- การ์ดหมวดหมู่ยังไม่นำทางไปหน้ารายการหนังสือที่กรองแล้ว
- ปุ่มเพิ่มรายการโปรด เลือกดาว และส่งรีวิวในหน้ารายละเอียดไม่เปลี่ยนข้อมูล
- สถานะอ่านแล้วในหน้ารายละเอียดอิงจำนวนตอนตัวอย่างคงที่ ไม่ได้บันทึกต่อผู้ใช้
- ปุ่มปรับขนาดตัวอักษร สลับโหมดกลางคืน และทำเครื่องหมายอ่านจบในหน้าผู้อ่าน
  ยังไม่มี action; การเลื่อนตอนก่อนหน้า/ถัดไปและปุ่มกลับทำงาน
- ปุ่มโหมดกลางคืนใน Sidebar ยังไม่มี action
- ไม่มีการจัดเก็บข้อมูลถาวร เมื่อปิดโปรแกรมการเปลี่ยนแปลงระหว่างใช้งานหายไป
- ก่อนแจกจ่ายโปรเจกต์ต่อในวงกว้าง ให้ตรวจเงื่อนไขการใช้งานและการแจกจ่าย
  ของไฟล์ฟอนต์ทุกไฟล์ใน `fonts/` และเพิ่มข้อมูล attribution หากผู้ให้ฟอนต์กำหนด

ถ้าจะพัฒนาต่อเป็นแอปใช้งานจริง ควรแยกชั้นจัดเก็บข้อมูล เพิ่ม validation
และ error handling สำหรับ input เชื่อม action ของปุ่มให้ครบ และเพิ่มการทดสอบ
ทั้ง unit test และ UI interaction
